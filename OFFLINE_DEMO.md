# SecureMailScope Offline Demo

1. Install Python 3.11+.
2. Install `backend/requirements.txt`.
3. Start the backend with `uvicorn backend.main:app --host 127.0.0.1 --port 8000`.
4. Open `http://127.0.0.1:8000`.
5. Upload a PCAP/PCAPNG.
6. Demonstrate sessions, STARTTLS, TLS visibility, findings and posture score.
7. Disconnect Wi-Fi and repeat to demonstrate offline operation.

Do not describe synthetic/demo data as a real incident capture.
